# Local AI Document Chat

A local, containerised document-grounded chat service designed for safe,
observable, and explainable retrieval-augmented generation.

## Project goals

The service will provide:

- local document-grounded question answering
- support for UTF-8 `.txt` and `.md` documents
- automatic detection of document additions, modifications, renames, and removals
- progressive streamed responses
- source attribution
- explicit context budgeting
- protection against instruction-like content inside documents
- safe rendering of untrusted model and document content
- structured logging and request tracing
- fully local operation after required images and models have been pulled
